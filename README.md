# Biblioteca

Libros ilustrados y fáciles de leer sobre historia, ciencia y mucho más.

**Léela aquí:** https://adrianhuelamolopez.github.io/biblioteca/

En el móvil o la tableta puedes añadirla a la pantalla de inicio para abrirla como una app. Los libros que ya hayas abierto se pueden leer también sin conexión, y cada libro recuerda por dónde ibas para seguir leyendo en ese punto.

Este repositorio es la web ya construida: la estantería (`index.html`) y cada libro en `libros/<id>/`.
